Listo para programar

Toca los cuadros para activar o quitar golpes. En el teclado puedes usar las teclas 1–8 para elegir la figura correspondiente y 9 o 0 para Off. En el celular, selecciona la figura en el menú. El patrón se repite mientras esté reproduciéndose. Activa «Metrónomo» para oír un clic por cada paso según la figura seleccionada, con acento al inicio del compás y acento secundario en 6/8. Los sonidos son electrónicos y originales, no muestras extraídas de la Alesis SR16.

1. Instrumentos

Selecciona un instrumento para resaltarlo. Cada fila tiene sus propios pasos. Para cambiar el orden, arrastra el símbolo ☰ de una banda hacia arriba o abajo con el mouse o con el dedo.

2. Secuenciador · pasos y límites de compás

Al lado de cada instrumento tienes un menú: «Todos» activa todos los pasos; «Borrar» elimina todos los golpes de esa fila; «Saltar 1» activa uno y deja vacío el siguiente; «Saltar 2» activa uno y deja dos vacíos, y así hasta «Saltar 8». Elige uno de los cinco sonidos por instrumento y usa «Todos» para activar todos los pasos. La línea dorada marca el inicio de cada compás.

4. Tu proyecto

«Guardar proyecto» descarga un archivo JSON que puedes conservar y abrir después en otro dispositivo. El archivo MIDI sirve para importar el patrón en un DAW o secuenciador compatible.
